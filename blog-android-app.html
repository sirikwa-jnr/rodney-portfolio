Building My First Android App with Java & Android Studio

By Rodney Achota · July 2026 · 5 min read

Before July 2026, I had written Java for class assignments and small console programs. But building an Android app is a different world — you have layouts, activities, Gradle, permissions, emulators and real devices all talking to each other.

Here's how I built MyStudentProfile, my first Android app, and what I learned along the way.

Step 1: Installing Android Studio

Android Studio is the official IDE for Android development. It's built on IntelliJ IDEA and comes with the Android SDK, an emulator, and everything you need to build, test and ship apps.

Step 2: Understanding the Project Structure

  • app/java — Java code (Activities, Adapters, Models)
  • app/res/layout — XML files that define your screens
  • app/res/drawable — images and vector assets
  • AndroidManifest.xml — declares activities, permissions and app metadata
  • build.gradle — dependencies and build configuration

Once you understand that Java handles logic and XML handles layout, it clicks.

Step 3: Designing the UI

I used XML layouts with ConstraintLayout. I added TextView, EditText, ImageView and Button components, gave them IDs, and referenced them in Java.

Step 4: Writing the Logic in Java

In my MainActivity.java, I used setContentView(), findViewById(), click listeners, input validation, and displayed results.

Step 5: Running on a Real Device

I enabled Developer Options and USB Debugging, connected my Android device via USB, and clicked Run. Watching my app open on my own phone was one of the best moments of my training.

Where the Code Lives

You can find the project on my GitHub: github.com/sirikwa-jnr/MyStudentProfilee

Final Thoughts

Android development is not easy, but it is learnable. Build one small app. That's how it starts.

— Rodney Achota
